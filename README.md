# Portfolio Website

Dit is mijn persoonlijke portfolio website waarin ik mijn projecten, vaardigheden en ervaringen presenteer. De website is ontwikkeld als onderdeel van mijn opleiding **Internet of Things**.

## Inhoud
- Homepagina met persoonlijke voorstelling
- Overzicht van mijn projecten
- Detailpagina’s van verschillende projecten
- Contactformulier (werkt met Netlify Forms)
- Social media links
- Dark/Light theme switcher

## Functionaliteiten
- Responsive design met Bootstrap 5
- Dynamische carousel op de homepage
- Netlify formulier voor contactberichten
- Thema-schakelaar (dark/light mode)
- Opslaan van gekozen thema via localStorage

## Technieken
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Netlify

## Doel van het project
Het doel van dit project is om mijn vaardigheden in front-end development te verbeteren en een professioneel ogende portfolio website te bouwen waarin mijn projecten en groei als developer zichtbaar worden.

## Contact
Voor vragen of feedback kan je mij bereiken via het contactformulier op de website.
